## Lollipop has moved to [lollipopoverlays.com](https://lollipopoverlays.com)

Downloads, help and what's new in every version are on the website now: **[lollipopoverlays.com](https://lollipopoverlays.com)**.

This page is no longer updated. It keeps one release, 0.4.15, so copies of Lollipop that still look here can update once. From 0.4.15 on, Lollipop finds new versions on the website by itself.

## Using an older version?

- **0.4.2 to 0.4.14:** use **Update now** on Home as usual. You'll get 0.4.15, and after that every update comes from the website.
- **0.4.1 or older, or RaceOverlay:** these can't install updates by themselves. Download Lollipop from **[lollipopoverlays.com](https://lollipopoverlays.com)** and run it once. Your settings stay as they are.
